# Spanish (es)

Reference for a native Spanish speaker's judgement. Default variant: neutral Spanish from Spain unless a Latin American target is chosen; always state the variant.

## Spelling and grammar essentials

- Opening marks are required: `¿Qué tal?`, `¡Bienvenido!`. Accent (`tilde`) rules: `qué/que`, `él/el`, `tú/tu`, `sí/si`, `más/mas`, `está`; capitals take accents too (`Opción`).
- Nouns have gender; adjectives agree. `el/un` before feminine nouns beginning with stressed `a` (`el agua`, `esta agua`). Subject pronouns are usually dropped.
- `ser` (identity, characteristics) vs `estar` (state, location); `por` (cause, route) vs `para` (purpose, destination).
- Subjunctive after `quiero que`, `para que`, `aunque` (hypothetical); `si` clauses: `si tengo` / `si tuviera … tendría`.
- Clitics: `Regístrate`, `Envíalo`, `Dímelo` (accent keeps stress). Leísmo/laísmo are regional; use the standard `le/lo/la`.
- No gender-inclusive `@/x/e` in standard text (RAE rejects it); prefer epicene words (`las personas usuarias`, `el equipo`).

## Typography

- Quotes `«…»` (also `“…”`); space not before `: ; ! ?`. Numbers: RAE recommends `1.234,56` but Latin America (Mexico, others) uses `1,234.56`; short numbers `1234`. Currency `25 €` (Spain) or `$25`.
- Dates `16 de octubre de 2026`; months and days lowercase; UI labels capitalise the first word only. `correo electrónico` or `email`/`e-mail`.
- Tilde on `solo` and demonstratives is no longer required (RAE 2010).

## Register and address

- Spain: `tú` (informal), `usted` (formal), `vosotros` (informal plural). Latin America: `tú`/`usted` and `ustedes` for plurals; Argentina, Uruguay, Central America use `vos` (`vos tenés`). Pick one for the product.
- Buttons: infinitive or noun (`Guardar`, `Eliminar`, `Iniciar sesión`); instructions: `tú` imperative (`Introduce un importe`).
- Polite: `por favor`, `gracias`; warm tone is natural, but UI stays concise.

## How people really talk

- Spain: `vale`, `venga`, `tío/tía`, `guay`, `mola`, `qué va`, `pues`, `en plan`, `o sea`. Mexico: `órale`, `chido`, `ahorita`. Argentina: `che`, `re`, `copado`, `boludo`.
- Vocabulary varies: `móvil` (ES) / `celular` (LatAm); `ordenador` / `computadora`; `ahora` / `ahorita`; `coger` is vulgar in Argentina/Mexico.
- Texting: `q`, `xq`, `tb`, `jaja`, `jeje`.

## Regional notes

- Choose `es-ES`, `es-MX`, `es-AR`, `es-419` (neutral Latin American) explicitly; date and number formats and some vocabulary differ.

- Variants (locale code, e.g. `es-MX`): load `references/variants.md` when the project locale has a region or is unknown.
