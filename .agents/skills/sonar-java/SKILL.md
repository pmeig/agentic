# Sonar for Java (on request only)

Used by `qa` to answer `front` / `back`, and to write the Sonar configuration of a Java module (`sonar-report`, `references/exclusions.md`).

## Properties

Model: `pmeig/github-actions/actions/java/sonar/properties`. When `sonar-project.properties` exists, keep it and add to it.

- `sonar.projectKey=<repository>`, `sonar.sourceEncoding=UTF-8`, `sonar.language=java`, `sonar.qualitygate.wait=true`.
- `sonar.java.binaries` pointing at the compiled classes (`target/classes`, `build/classes/java/main`); `sonar.java.libraries` with the
  Lombok jar when Lombok is used (copied by `maven-dependency-plugin` `copy-dependencies`, as the action does).
- `sonar.java.coveragePlugin=jacoco`, `sonar.coverage.jacoco.xmlReportPaths=<module>/target/site/jacoco/jacoco.xml`
  (multi-module Maven: the `jacoco-aggregate` report of a `sonar-report` module; Gradle: `build/reports/jacoco/test/jacocoTestReport.xml`).
- Build side: Maven `jacoco-maven-plugin` (`prepare-agent` + `report` at `verify`, `report-aggregate` for several modules) and
  `sonar-maven-plugin`; Gradle `jacoco` plugin with `xml.required = true` and the `org.sonarqube` plugin.

## Out of the analysis

- Tests: `sonar.tests=src/test/java`, `sonar.test.inclusions=**/*Test.java,**/*Tests.java,**/*IT.java`;
  `sonar.coverage.exclusions` and `sonar.cpd.exclusions` contain `**/src/test/**`.
- Without behavior (`sonar.coverage.exclusions`): `**/configuration/**`, `**/*Configuration.*`, `**/properties/**`, `**/*Properties.*`,
  `**/model/**`, `**/dto/**`, `**/entity/**`, `**/repository/**` (interfaces), `**/exception/**`, `**/*Exception.*`, `**/*Application.*`,
  generated sources (MapStruct, OpenAPI, QueryDSL), `**/helper/**` only when it holds constants or branch-free mappers.
- Jacoco `excludes` for generated bytecode: Lombok is handled with `lombok.addLombokGeneratedAnnotation = true` in `lombok.config`.
