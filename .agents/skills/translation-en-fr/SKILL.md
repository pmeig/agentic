# English → French

You are a **native French speaker** reading English as a foreign language. Load it with `translation-craft`, `language-fr` and `language-en`.

## Structural contrasts

- English noun stacks become `de`/`à` phrases: `session invitation link` → `lien d'invitation à la session`.
- English phrasal verbs and manner verbs: put the path in the verb, the manner aside (`walk in` → `entrer`, `sign in` → `se connecter`).
- English passive and `you` instructions become active/`on`/reflexive (`The file was deleted` → `Le fichier a été supprimé` / `On a supprimé le fichier`; `This is sold here` → `Ça se vend ici`).
- Bare English `-ing`/infinitive subjects need an article or infinitive in French (`Saving fails` → `L'enregistrement échoue`).

## False friends and traps

- `actually` ≠ `actuellement` (= `en fait`); `eventually` ≠ `éventuellement` (= `finalement`); `library` ≠ `librairie` (= `bibliothèque`); `sensible` ≠ `sensible` (= `raisonnable`); `to attend` ≠ `attendre` (= `assister à`); `location` ≠ `location` (= `emplacement`); `to pretend` ≠ `prétendre`; `to demand` ≠ `demander`; `resume` ≠ `résumer`; `deception` ≠ `déception`.

## Idioms and register shifts

- `Heads up` → `À savoir`, `Petite info`; `Got it` → `Compris`, `OK, noté`; `Hang on` → `Un instant`, `Une seconde`; `No worries` → `Pas de souci`, `Aucun problème`; `It's on me` → `C'est pour moi`, `Je t'invite`.
- English understatement and enthusiasm: tone down exclamation marks in neutral French; French `tu` adds warmth that English gets from contractions.

## Formats and typography

- Narrow no-break space before `: ; ! ? »`; `« … »` quotes; `1 234,56 €`; `16 octobre 2026`; lowercase months and days; sentence case in UI.

## Length and UI

- French is 15–25 % longer: prefer a verb to `Faire une…`, drop `s'il te plaît` in buttons, use the infinitive for actions (`Enregistrer`).

## Frequent decisions

- `tu` for consumer apps, `vous` for institutions; keep it fixed. `Save` → `Enregistrer`, `Delete` → `Supprimer`, `Cancel` → `Annuler`, `Settings` → `Paramètres`, `Sign up` → `S'inscrire`, `Sign in` → `Se connecter`, `Email` → `E-mail` (or `Courriel` in Québec).
