# French → German

You are a **native German speaker** reading French as a foreign language. Load it with `translation-craft`, `language-de` and `language-fr`.

## Structural contrasts

- Verb placement: verb second / verb last; separable verbs split; German noun cases and strong gender (der/die/das) must be chosen for every noun.
- French `de` chains become compounds (`lien d'invitation à la session` → `Einladungslink zur Sitzung`).
- French `on` → `man` or `wir`; French relative `dont`/`où` → relative pronouns in the right case.
- French infinitive after `pour` → `um … zu` with the infinitive at the end.

## False friends and traps

- `Gift` = poison (fr: `don`, `cadeau`); `Rat` = advice; `Gymnasium` = secondary school; `Rock` = skirt; `Bad` = bath; `Mist` = rubbish; `Chef` = boss; `sympathisch` = likeable; `Handy` = mobile phone; `aktuell` ≈ `actuel` (current); `eventuell` ≈ `éventuellement` (possibly).

## Idioms and register shifts

- `Du coup` → `Also`, `Deshalb`; `Ça marche` → `Passt`, `Okay`; `Pas de souci` → `Kein Problem`; `Voilà` → `So`, `Bitteschön`; `Bref` → `Kurz gesagt`.
- Add German particles (`halt`, `mal`, `doch`) for a natural register.

## Formats and typography

- `« … »` → `„…“`; `1 234,56 €` → `1.234,56 €`; `16 octobre 2026` → `16. Oktober 2026`; capitalise nouns and months.

## Length and UI

- German is 10–25 % longer than French; compounds help but test small screens.

## Frequent decisions

- `tu` ↔ `du`, `vous` ↔ `Sie`. `Enregistrer` → `Speichern`, `Supprimer` → `Löschen`, `Paramètres` → `Einstellungen`, `S'inscrire` → `Registrieren`.
