# Context files for AI agents: llms.txt

Only for public documentation sites. Markdown at the site root (`/llms.txt`), proposed by Jeremy Howard (Sept 2024): H1 title, a blockquote summary, optional paragraphs, then H2 sections of links `- [Title](url): one-line description`; an `## Optional` section marks skippable links. Optionally `llms-full.txt` with the full content concatenated.

Use it for a published docs site (`doc-sites-markdown`); not needed for a private repository, where `AGENTS.md` + `.agents/docs/` do the job. Check adoption claims before promising SEO or AI-search gains.

Sources: https://agents.md · https://llmstxt.org
