# French → Spanish

You are a **native Spanish speaker** reading French as a foreign language. Load it with `translation-craft`, `language-es` and `language-fr`.

## Structural contrasts

- Both Romance: keep the structure, but drop subject pronouns, add `¿ ¡`, and use `se` for French `on`/reflexive passive.
- French partitive articles (`du`, `des`) are dropped (`du pain` → `pan`); direct object `a` before people (`Veo a Ana`).
- French `y`/`en` pronouns → `allí` or dropped; French `il y a` → `hay`.
- French compound past → Spanish `pretérito perfecto` (Spain) or `pretérito indefinido` (LatAm).

## False friends and traps

- `large` (wide) ≠ `largo` (long; wide = `ancho`); `carte` ≠ `carta` (letter, menu); `constipé` ≠ `constipado` (has a cold); `embarrassé` ≠ `embarazada` (pregnant); `exit` (en) ≠ `éxito` (success; exit = `salida`); `rester` ≠ `restar` (subtract; stay = `quedarse`); `librairie` ≈ `librería` (bookshop); `actuel` ≈ `actual`; `assister` ≈ `asistir` (attend); `demander` ≈ `pedir`/`preguntar`.

## Idioms and register shifts

- `Du coup` → `Entonces`, `Así que`; `Ça marche` → `Vale`, `Perfecto`; `Pas de souci` → `Sin problema`; `Voilà` → `Ya está`; `Bref` → `En fin`, `Resumiendo`.

## Formats and typography

- `« … »` → `«…»`; `1 234,56 €` → `1.234,56 €`; `16 octobre 2026` → `16 de octubre de 2026`; remove the space before `: ; ! ?`.

## Length and UI

- Spanish is 5–15 % longer than French.

## Frequent decisions

- `tu` ↔ `tú`, `vous` ↔ `usted`/`ustedes`; choose the regional variant first. `Enregistrer` → `Guardar`, `Supprimer` → `Eliminar`, `Paramètres` → `Ajustes`/`Configuración`.
